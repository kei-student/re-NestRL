# 左L1の動きと失敗行動（2026-11-15）

各環境からseed101を1体ずつ選び、右L0三種との9組み合わせを可視化した。
選択は最初のconstruction seedで固定し、成績による選別はしていない。
表示するのは保存済み評価の最初のround・5エピソード、合計45エピソード。
以下の集計は短い映像だけではなく、この3体の全9,000エピソードを再生して求めた。
ほかの9体の行動は今回の分析対象に含めない。

## 観察と分析

### 環境1：全体観測・調理制限なし

玉ねぎL0にはレタス、にんじんL0には主にトマトを調理できている。
一方、ブロッコリーL0に必要なじゃがいもは**1,000回中一度も調理しなかった**。
998回はレタスとトマトの両方を調理し、残る2回はレタスのみを調理した。
最終皿は968回が「レタス＋トマト＋ブロッコリー」、32回が「レタス＋ブロッコリー」。
このため相手の固定レシピを完成できず、全1,000回が時間切れになる。

最初の映像は、t5でレタスを取り、t9で調理、t13で皿に投入する。
L0はt15でブロッコリーを加えて待つ。L1はt19で生のじゃがいもを取るが、
上のカウンターに置き、t32でトマトを調理してt36で皿に加える。
正しいじゃがいもを取り上げること自体は全1,000回で起きているが、調理には進まない。

にんじんL0の999成功回とは対照的で、単に全レシピが実行不能という結果ではない。
残る1失敗回はレタスも混入し、皿が「レタス＋トマト＋にんじん」になっていた。

### 環境2：自分側＋共有カウンター観測・1食材制限

にんじんL0とブロッコリーL0に対し、それぞれ999/1,000回はレタスだけを調理し、
各1回は何も調理しなかった。正しいトマト／じゃがいもの調理はともに0回。
失敗後は生の別食材を持ち上げたり移動したりするが、調理する種類は変わらない。

相手の食材変化が初めて見える時刻は平均t13.55／t14.53だが、最初の調理は
平均t8.00／t7.97。各995回で、可視の手掛かりを得る前または同時の行動で調理済みだった。
レタスを調理した時点でそのエピソードの種類が確定するため、その後は必要な別種を調理できない。
最初の生食材取得が可視の手掛かりより後だった回は、この条件では0/3,000回。

最初のにんじんL0回では、t8にレタスの制限が確定し、t12にレタス＋にんじんが皿に入り、
以後配膳できない。トマトは初期位置から最短2行動で取得できる一方、レタスは4行動必要だった。
それでもレタスへ向かったため、単純な「最寄りの食材を選ぶ」だけでは説明できない。

### 環境3：全体観測・1食材制限

どのL0相手でも、調理したのは全3,000回でレタスのみ。
にんじん／ブロッコリーL0に必要な食材を調理した回は0/2,000回だった。
相手食材の変化は平均t3.84／t4.48で見えるが、最初の調理は平均t9.24／t9.52。
全体観測で手掛かりを得られる時間があっても、調理食材は切り替わっていない。
したがって、今回の失敗全体を「相手の厨房が見えないため」だけで説明することはできない。

最初のにんじんL0回は、L0がt3ににんじんを取った後、L1がt7にレタスを取り、
t11に調理する。さらにL1自身がにんじん入りの皿を左側へ取り、t20にレタスを加える。
皿は間違った組み合わせのままで、L0は配膳しない。

## 待機と配膳について

失敗回で長く待っている主役は、多くの場合**L0側**である。
L0は自分の食材を皿に入れた後、指定の正しい2食材が揃うまで待つ固定仕様で、
失敗する各組み合わせでは平均25.1–26.4行動がこの待機だった。
正しくない皿を見て止まる動きはL0の仕様と一致し、動作停止や描画不良ではない。

L1側は、誤った食材を調理・投入し、皿を取ったり生の別食材を運んだりして時間切れになる。
観測前の連続不変状態が3行動以上あり、最初の生食材取得が観測後だった回は、
環境1の失敗するブロッコリー相手では4/1,000回、環境2の失敗2組と環境3の失敗2組では0回。
この記述統計は意図を推定するものではなく、論文の情報獲得目的の待機を認定する基準でもない。
今回の3体の主要な失敗は、待機して正しい食材へ適応する行動とは異なる。

5エピソードroundの後半でも、これら失敗する組み合わせは成功0/200回ずつだった。
映像のepisode2–5を選ぶと、同じ相手を繰り返しても必要な食材に切り替わらない様子を確認できる。

## 解釈の範囲と仮説

「食材を持ち上げる」「調理する」「皿に加える」を区別する必要がある。
例えば環境1のにんじんL0では79%が最初にじゃがいもを取得するが、99.9%は最終的にトマトを調理して成功する。
持ち上げた食材だけを見て、最終的なレシピ選択や調理制限違反と判断できない。
1食材制限は調理に適用され、生食材を複数種類持ち運ぶことは許可されている。

私の解釈では、制限なしの環境1ではレタス／トマトの協調手順は学習できたが、
じゃがいもの調理へ分岐する手順が獲得されていない。制限ありの環境2・3では、
レタスを調理する行動への偏りが強く、相手に応じた調理種類の選択が未獲得である。

失敗しても平均returnは環境1ブロッコリー相手で7.66、環境2で6.21／6.31、
環境3で6.71／6.83あり、配膳報酬は全て0である。
食材や皿の取得・途中進捗の報酬は得られるため、こうした手順が部分報酬で維持された可能性がある。
成功回でも完成前に不要な生食材を取る例があり、最短手順の獲得とは異なる。
ただし報酬を変えた比較実験は行っておらず、これを学習失敗の原因と断定はしない。
