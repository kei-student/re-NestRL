## 個体別設定と成果物準備

[study](../configs/l2-env3-coverage-1000u-20261117.json)からconfigとselectionを生成する。
181はコマンドの例。learner seed・人数は本実験起動時に指定する。

```sh
source .venv/bin/activate
python scripts/create_l2_coverage_config.py \
  --learner-seed 181 --output-root outputs/coverage-l2-example-181
python scripts/prepare_l2.py \
  --config outputs/coverage-l2-example-181/config.json \
  --catalog configs/partner_pools/env3-passing15-20261116.json \
  --archives-dir PATH_TO_VERIFIED_ARCHIVES \
  --output-root outputs/coverage-l2-example-181
```

これらのコマンドは学習を起動しない。抽選はlearner seedから導出せずOS乱数を使用する。
`--selection-seed`は記録済み抽選の再現用。既存output-rootへの再作成は拒否する。
別L2の抽選が偶然一致することは許す。再開では保存済みconfigを再利用する。

生成configには、通常の `l1_pool` に選択済み3体を指定し、次を追加する。

```json
{"l2_mixture": {
  "l0_recipes": ["LettuceOnionSalad", "TomatoCarrotSalad", "PotatoBroccoliSalad"],
  "sampling": "uniform_per_partner_per_round"
}}
```

上記は抜粋。完全なconfigは生成scriptを正本とする。
将来の学習は生成configと同じoutput-rootでstage=l2を明示する。
人数・learner seeds・並列数・Draft保存先を起動時に決め、先行1タスクを検証してから展開する。
新しいCloudタスク・定期ジョブは今回作成していない。

training_partnersはL1三体、L0三体の順で全6体を記録する。
partner_samplingに抽選法・順序・確率を保持する。
エピソードログにはpartner_index/id/level・env_indexを保存する。
snapshotは相手index・L1 GRU・L0の状態/RNG・learner/collector/RNGを復元する。

## 比較評価と互換性

既存1000更新L2と同じ確率的行動・seed6001・各固定L0に1000回、
共通L1 15体それぞれ1000回・5エピソード履歴で比較する。

被覆L2にとってL0は直接の学習相手なので、元L1のみL2との比較で
「学習に未使用の相手」という意味は異なる。
L1は既知3体と未使用12体を分け、共通15体平均も示す。性能評価自体はまだ行っていない。

環境・105入力・model・固定L0/PACEは変更していない。
旧L1は元manifest/configのまま厳密推論できることを実物で確認した。
未指定のl2_mixtureをcanonical表現から省略し、既存config hashを維持する。
学習処理のsource hashは変わるため、旧runの厳密な学習再開は旧ソースで行う。
被覆条件は新config・新run・新規初期化であり、既存runを書き換えない。
